# 两个概念：
1. 优化器
一般采用梯度下降算法更新模型参数，目标是最小化损失函数
传统梯度下降方法具有多种弊端：
(1) 容易陷入鞍点 (2) 缺乏加速机制 (3) 难以跳出局部最小值区域 (4) 无法适应复杂地形
(5) 容易产生严重震荡 (6) 无法自适应调整学习率
过程优化：动量法、AdaGrad、RMSProp和Adam
a. 动量法：
v = momentum * v_prev + gradient -- 累积动量
params = params - lr * v -- 用动量更新参数
有"记忆"功能，记住之前的方向，在同一方向连续移动时会加速，从而能够冲过小的上坡和坑洼，并减少来回摇摆，更稳定；
但是可能冲过头，错过最优点；且学习率lr仍为定值
b. AdaGrad
G += gradient²  --累积梯度平方
params = params - lr * gradient / sqrt(G + ε)  --自适应学习率
记录每个方向走过多少步，在走得少的方向上大步走，在走得多的方向上小步走，自动调整每个参数的学习率
但是G单调增加，使学习率单调递减，后期可能过小，导致过早停止学习
c. RMSProp
G = decay * G + (1-decay) * gradient²  --指数移动平均
params = params - lr * gradient / sqrt(G + ε) --自适应学习率
改进AdaGrad，用指数移动平均代替简单累积，避免学习率过快衰减
但仍然没有动量机制，可能在某些情况下不稳定
d. Adam
m = β1 * m + (1-β1) * gradient        - 动量（一阶矩）
v = β2 * v + (1-β2) * gradient²       - 自适应学习率（二阶矩）
m_hat = m / (1 - β1^t)                - 偏差修正
v_hat = v / (1 - β2^t)                - 偏差修正 
结合了Momentum和RMSProp的优点，既有动量记忆（记住方向），又有自适应学习率（记住步长），还有偏差修正机制

2. 卷积层
以自己训练的网络为例：
输入: (batch, 3, 64, 64) → 输出: (batch, 32, 62, 62)
解释：3是输入通道(RGB)，32是输出通道(特征数量)，3x3是卷积核大小
为什么是 (64 - 3) / 1 + 1 = 62: 
64长度-3卷积核长度=能移动的长度61，61/1步长=步数61，+1得到输出长度62
所谓“卷积核组数=输出通道数”：
输入通道3，则每组卷积核有3个，分别提取R、G、B通道特征
输出通道是人为规定的超参数，想要32个特征图，就设置32个卷积核组
