# 网络设计：
## 特征提取部分（4层卷积）
输入: (batch, 3, 64, 64)

Conv1: 3→32, 3×3卷积 → (batch, 32, 62, 62)
BatchNorm + ReLU + MaxPool2d → (batch, 32, 31, 31)

Conv2: 32→64, 3×3卷积 → (batch, 64, 29, 29)  
BatchNorm + ReLU + MaxPool2d → (batch, 64, 14, 14)

Conv3: 64→128, 3×3卷积 → (batch, 128, 12, 12)
BatchNorm + ReLU + MaxPool2d → (batch, 128, 6, 6)

Conv4: 128→256, 3×3卷积 → (batch, 256, 4, 4)
BatchNorm + ReLU + AdaptiveAvgPool2d(2×2) → (batch, 256, 2, 2)

## 分类器部分（3层全连接）
Flatten: (batch, 256, 2, 2) → (batch, 1024)

FC1: 1024→512 + ReLU + Dropout(0.5)
FC2: 512→128 + ReLU + Dropout(0.5)  
FC3: 128→3 (最终分类输出)、

2. 数据预处理设置
统一图片尺寸为64×64，PIL图像→PyTorch张量，[0,255]→[0,1]
3. 超参数和数据加载
每批处理1024张图片,训练200轮;加载三个数据集,创建数据加载器
4. 设备和网络初始化
将网络移到GPU, 设置损失函数(三分类交叉熵损失)和优化器(随机梯度下降算法)
5. 训练循环
遍历每个批次：
    （1）前向传播：清零梯度，运行网络预测，计算损失；
    （2）反向传播：计算梯度，更新参数，累计损失
6. 模型评估和保存机制：
    评估条件：第50轮后，每10轮评估一次
    评估流程：
    (1) 保存临时模型
    (2) 加载模型进行测试
    (3) 在两个测试集上评估, 选择概率最大的类别，统计正确数量
    最佳模型保存：计算准确率，如果测试集1准确率超过历史最高，则保存为最佳历史模型
